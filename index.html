Generación de Violin plot para evap_soim setiembre 2026

Es un gráfico adecuado para mostrar las densidades de probabilidades que toman los conjuntos de datos. Muestra información sobre que valores se “repiten” más en los datos. Es buena práctica combinarlo con medidas de tendencia central y dispersión, como un boxplot. El código que genera los gráficos fue suministrado por el Prof. Esteban A. Montero-Sánchez, MSc y, modificado por los estudiantes D. Moya, M. Rodríguez y D. Chávez.

1. Climatología:

climatology_labels <- c(
  "1" = "Transition",
  "2" = "Non-seasonal",
  "3" = "Seasonal"
)
to_long <- function(df, variable_label) {
  scenario_cols <- setdiff(names(df), c("basin", "cluster_3"))
  
  df %>%
    pivot_longer(cols = all_of(scenario_cols),
                 names_to = "scenario", values_to = "delta") %>%
    mutate(variable = variable_label)
}

datos_long <- bind_rows(
  to_long(delta_evap, "Evapotranspiration"),
  to_long(delta_soim, "Soil water storage")
) %>%
  mutate(
    climatology = recode(as.character(cluster_3), !!!climatology_labels),
    climatology = fct_relevel(climatology, "Seasonal", "Transition", "Non-seasonal"),
    
    ## no contiene literalmente "15", "25", "50"
    scenario = case_when(
      str_detect(scenario, "15") ~ "afforestation_15",
      str_detect(scenario, "25") ~ "deforestation_25",
      str_detect(scenario, "50") ~ "deforestation_50",
      TRUE ~ NA_character_
    ),
    scenario = fct_relevel(scenario, "afforestation_15", "deforestation_25", "deforestation_50"),
    
    variable = fct_relevel(variable, "Evapotranspiration", "Soil water storage")
  )
scenario_labels <- c(
  "afforestation_15" = "+15%",
  "deforestation_25" = "-25%",
  "deforestation_50" = "-50%"
)

Definición de paleta de colores para las categorías de climatología

Para orientar la interpretación de los gráficos, se define una paleta de colores que asocia cada categoría de climatología con un color específico. Esto permite identificar visualmente las diferencias entre las categorías en los gráficos generados. Para ello, se asignan los siguientes colores a cada categoría: Seasonal = naranja, Transition = amarillo, Non-seasonal = verde

climatology_colors <- c(
  "Seasonal"     = "#F5A623",
  "Transition"   = "#F6D965",
  "Non-seasonal" = "#4C9A2A"
)

El gráfico resultante evalúa la variación relativa (%) de la evapotranspiración (ET) y el almacenamiento de agua en el suelo (Soil water storage - SWS) bajo tres escenarios de cambio en la cobertura boscosa (+15%, -25% y -50%), divididos en tres clústeres hidrometeorológicos (Seasonal o Estacional, Transition o Transición y Non-seasonal o No estacional).

Desde una perspectiva ecohidrológica, el gráfico demuestra que los bosques actúan como reguladores del ciclo del agua. La reducción drástica de la cobertura boscosa (-50%) no solo disminuye el flujo de vapor de agua hacia la atmósfera (ET), sino que impacta comprometiendo la recarga y la disponibilidad de humedad en el suelo. Esto advierte sobre los riesgos asociados a la deforestación en distintas regiones climáticas.
